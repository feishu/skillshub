# 中文简历模板（中国职场 / 技术岗默认版）

> 目标：让 HR/面试官在 30 秒内定位到 **你是谁、要什么岗位、最强证据是什么**。

# 姓名（英文名可选）
**求职意向：XX工程师 / XX方向**｜城市：XX｜电话：XX｜邮箱：XX｜GitHub/博客（可选）｜到岗：XX｜状态：在职/离职/应届

## 个人亮点（3 行以内）
- 用 1 句讲清“年限 + 领域 + 核心能力”。
- 用 1 句讲清“最硬的结果/指标”。
- 用 1 句讲清“与目标岗位最对口的技术栈/业务域”。

## 专业技能（分层）
- **熟练**：A / B / C（能独立落地、能定位问题、能讲清原理）
- **掌握**：D / E（做过完整功能或项目，但深度有限）
- **了解**：F / G（用过/看过，能配合但不主导）
- **工程化与方法论（可抽象复用）**：把可迁移的能力从经历中上提（例如 AI Coding 治理与落地、稳定性治理、交付协作闭环），让经历负责“证据链”，技能负责“能力框架”。

## 工作经历（倒序）
### 公司｜部门（可选）｜岗位｜城市｜YYYY.MM - YYYY.MM
**背景/业务**：一句话说明产品/系统是什么、服务谁、体量如何（用户/DAU/QPS/数据量/营收口径任选其一）。

- **动作 + 方法 + 结果（指标）**：例如“重构支付回调链路，引入幂等与重试，退款失败率从 X% 降到 Y%”。
- **动作 + 约束 + 结果（周期/成本）**：例如“在双周迭代约束下，交付XX功能，提前X天上线，节省X人天”。
- **动作 + 协作边界 + 产物**：例如“与风控/运营对齐规则，产出字段字典与回溯脚本，支持灰度与回滚”。

**技术栈（只写与你结果相关的）**：XX，XX，XX

## 项目经历（倒序 / 与目标岗位最相关的优先）
### 项目名｜你的角色（Owner/主导/核心参与）｜YYYY.MM - YYYY.MM
**S（情境/问题）**：一句话说明为什么要做（痛点/指标/风险）。

**T（任务/目标）**：一句话说明目标（指标化优先）。

**A（行动/方案）**：3–5 条 bullet，写“你做了什么”，每条都要有对象与方法。
- 例：设计XX方案，拆成XX模块，解决XX瓶颈（解释关键决策点）。
- 例：落地XX监控/压测/灰度机制，保证XX稳定性。

**R（结果/影响）**：必须写结果，优先量化。
- 例：峰值 QPS 提升 X%，P95 延迟降低 Yms，故障率降低 Z%。
- 例：业务转化提升 X%，成本下降 Y%，人效提升 Z%。

**技术栈**：只列和行动/结果直接相关的。
