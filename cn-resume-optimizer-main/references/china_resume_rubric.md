# 中国职场简历优化 Rubric（评估与改写参考模板）

这份 Rubric 的目标是把“简历好不好”拆成可复用的检查项，让优化不靠主观口味，而靠一套能稳定抓重点的评价函数。它聚焦中国招聘的真实筛选链路：**硬条件筛选 → 对口度判断 → 经历可信度 → 结果与影响 → 细节可追问**。

## 1. 一眼筛选（0-10 分）

在中国职场，简历的第一轮常常是 10–30 秒的“扫读”。这一段的标准不是文采，而是**信息密度 + 可定位性**。

- **抬头信息完整**：姓名、城市、电话、邮箱、求职意向（岗位/方向）、到岗时间/状态（在职/离职/应届）可快速定位。
- **时间线可读**：教育、工作、项目按时间顺序一致；同一段经历的起止时间、城市清晰。
- **篇幅与布局**：校招/初级默认 1 页；社招通常 1–2 页；标题层级一致，避免花哨图形/多栏导致解析困难。

扣分典型：缺城市/意向；日期混乱；关键信息藏在段落里；一页塞不下但又没有“优先级裁剪”。

## 2. 对口度（JD 对齐）（0-25 分）

对口度不是“关键词出现次数”，而是“JD 的核心要求能否在简历里被快速看见，并且每条要求后面跟着证据”。紧接着在中国语境里还要做一件事：把经历描述里的**产品归属/业务侧标签**收敛为真实定位（例如“公司侧低代码核心平台/可视化大屏平台/数据中台能力”），并使用更贴近绩效评审的语言（按期交付、稳定性治理、成本/效率改善、可复用沉淀），避免内部分类口径（如某些公司自定义的条线名称）让外部读者产生误解。

- **岗位画像对齐**：把 JD 拆成 *职责*、*能力*、*技术/工具*、*行业/业务域* 四类。
- **证据点映射**：每个关键要求至少对应 1 条经历证据（项目/职责/成果）。
- **优先级排序**：最对口的经历/项目必须前置（同一段经历里最相关的 bullet 也要前置）。

输出物要求：必须能生成一个“**匹配/部分匹配/缺口**”对齐表，而不是泛泛建议。

## 3. 结果导向与量化（0-25 分）

中国面试官读简历最在意的是：你做的事情有没有“可复述的结果”，以及这个结果在业务/工程上有多大分量。

- **结果句式**：动词 + 行动对象 + 方法/约束 + 结果（指标/规模/影响）。
- **可量化优先**：金额/成本/收入/转化、DAU/MAU、QPS/延迟、缺陷率、节省人力、交付周期、稳定性指标等。
- **不可量化也要可验证**：用“前后对比/覆盖范围/落地范围/上线频次/协作对象/产物”替代空泛形容词。

扣分典型：只有职责没有结果；用“优化/提升/负责”但没有对象与指标；堆砌名词不说明影响。

## 4. 可信度与可追问性（0-20 分）

中国面试很喜欢追问细节：你写的每一句都要能被追问到“你具体怎么做的”。

- **角色清晰**：你在团队中的位置（owner/主导/参与/协作）要写清楚。
- **边界清晰**：系统边界、规模边界（用户/数据/并发/团队规模）与约束条件（时间/资源/存量系统）要能说清。
- **产物清晰**：文档、代码模块、流程、指标看板、落地方案等“可交付物”要能点名。

扣分典型：把团队成果写成个人成果；动词过大（“架构/重构/主导”）但缺证据链；无法解释关键实现细节。

## 5. 结构与用词（0-20 分）

- **中国语境标题**：教育经历/工作经历/项目经历/专业技能/证书/奖项等用常见标题，利于 HR/系统快速定位。
- **技能分层**：熟练/掌握/了解分层；避免“精通”滥用（技术岗常见减分项）。
- **去口号化**：删除“学习能力强、抗压、沟通强”等没有证据的口号，改成事实与结果。
- **抽象上提**：把可复用、可迁移的能力从经历 bullet 中抽象出来，上提到技能区形成“方法论能力线”（例如：AI Coding 治理与落地、稳定性治理、交付与协作闭环）。经历里保留证据链（做了什么+结果），技能区负责总结能力框架（你会什么、怎么做）。

## 6. 产出模板（优化时必须同时生成）

优化不只输出“改写后的简历”，还必须输出两份可验证附加物：

- **改动说明（diff style）**：列出每一段改写对应原文与改写理由（对应 rubric 的哪一项）。
- **JD 对齐报告**：匹配/部分匹配/缺口表 + 缺口如何在经历中补证据（或在求职信/面试中补）。
